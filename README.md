# 🍱 Cantina da Bea — Site para Restaurante/Cantina

Site responsivo para cantina ou restaurante local — card de cardápio, galeria de fotos, botão de pedido pelo WhatsApp e layout mobile-first.

![Language](https://img.shields.io/badge/Stack-HTML%20%7C%20CSS%20%7C%20JS-orange) ![License](https://img.shields.io/badge/Licen%C3%A7a-MIT-blue)

---

## 🎯 O que tem

- Header fixo com navegação e botão direto pro WhatsApp
- Hero com foto de destaque e chamada para ação
- Seção de cardápio com cards por categoria
- Galeria de fotos do ambiente e pratos
- Formulário de contato / WhatsApp
- 100% responsivo, mobile-first
- Zero dependências externas (só Google Fonts)

## ⚙️ Como usar

1. Edite `index.html` — troque nome, fotos e número do WhatsApp
2. Suba para qualquer hospedagem PHP ou estática (Netlify, Cloudflare Pages, GitHub Pages)
3. Pronto — sem banco, sem backend
