# 🍱 Cantina da Bea — Site para Restaurante/Cantina

Site responsivo para cantina ou restaurante local — card de cardápio, galeria de fotos, botão de pedido pelo WhatsApp e layout mobile-first.

![Language](https://img.shields.io/badge/Stack-HTML%20%7C%20CSS%20%7C%20JS-orange) ![License](https://img.shields.io/badge/Licen%C3%A7a-MIT-blue)

---

## 🎯 O que tem

- Visual estilo cartaz, com as cores da marca (laranja, verde, creme e rosa)
- Seção "conheça a Bea" no topo, contando a história da casa
- Buffet livre com selo de preço e cards por categoria
- **Delivery:** página `pedido.html` com formulário simples (nome, endereço, número, ponto de referência e pedido) que abre o WhatsApp com a mensagem já preenchida
- Botões de WhatsApp no menu, na barra fixa do celular e no contato
- "Venha almoçar" abre o app de mapa do celular com a rota até o restaurante
- Galeria de fotos do ambiente e pratos
- 100% responsivo, mobile-first
- Zero dependências externas (só Google Fonts)

## ⚙️ Como usar

1. Edite `index.html` e `pedido.html` — troque nome, fotos, endereço e número do WhatsApp (`wa.me/55DDDNUMERO`)
2. Suba para qualquer hospedagem estática (Netlify, Cloudflare Pages, GitHub Pages)
3. Pronto — sem banco, sem backend
